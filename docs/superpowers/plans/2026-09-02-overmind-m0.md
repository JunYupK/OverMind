# OverMind M0 구현 플랜

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** observation을 PostgreSQL에 영속화하고 원격 MCP `remember_memory`/`recall_memory` 두 도구로 저장·조회하는 첫 수직 슬라이스를 완성한다.

**Architecture:** Hexagonal vertical slice. inbound MCP 어댑터가 MCP 스키마를 application command/query로 바꾸고, application은 port로만 바깥과 통신하며, JPA/PostgreSQL 어댑터가 이를 구현한다. canonicalization·LLM·비동기 작업은 없다.

**Tech Stack:** Java 21, **Spring Boot 4.1.1**, Spring AI 2.0.1 MCP Server (WebMVC, Streamable HTTP), Spring Security OAuth2 Resource Server, Hibernate 7.4.5 / jakarta.persistence 3.2.0, Flyway 12.4.0, PostgreSQL 16, JUnit 5, AssertJ, ArchUnit, Testcontainers

**Spec:** `docs/superpowers/specs/2026-09-02-overmind-m0-design.md`

## Global Constraints

스펙과 이 저장소의 기존 게이트에서 온 프로젝트 전역 요구사항이다. **모든 태스크의 요구사항에 암묵적으로 포함된다.**

### 스펙에서

- `content`는 nonblank, UTF-8 기준 최대 **16 KiB**.
- `idempotency_key`는 필수, UTF-8 최대 **256 bytes**, **전역 unique**.
- `source_client`는 필수, UTF-8 최대 **128 bytes**.
- `source_conversation_id`·`source_message_id`는 필수, 각각 UTF-8 최대 **512 bytes**.
- PROJECT key는 1~128자, 정규식 `[a-z0-9][a-z0-9._-]*`.
- `observed_at`은 서버 시각 **+5분까지 허용**, 초과는 거부.
- recall `limit` 기본 **20**, 범위 **1~100**.
- recall 한 페이지 content 총합 예산 **2 MiB**.
- 정렬은 항상 `observed_at DESC, created_at DESC, id DESC`.
- 오류 코드는 `INVALID_ARGUMENT` / `SUBJECT_NOT_FOUND` / `IDEMPOTENCY_CONFLICT` / `INVALID_CURSOR` / `UNAUTHENTICATED` / `PERMISSION_DENIED` / `INTERNAL_ERROR` **일곱 개뿐**.
- scope는 `memory:read`(recall) / `memory:write`(remember) 두 개뿐. delete 도구도 `memory:delete`도 없다.
- observation은 append-only. 일반 persistence port에 update/delete 연산을 두지 않는다.
- **로그·오류 응답에 절대 넣지 않는다:** content, source reference, idempotency key, project key 원문, token/claim, cursor 원문, stack trace, DB 예외.

### 이 저장소의 게이트에서

- **INV-02 (`LayerDependencyTest`)**: `com.overmind.domain..`에 `toString` 메서드가 있으면 실패한다. **Java `record`는 `toString`을 바이트코드로 생성하므로 도메인에 record를 쓸 수 없다.** 도메인 값은 `final class`로 만들고 `equals`/`hashCode`만 직접 구현한다. 스펙 §8이 말한 "record 대신 안전한 immutable class"가 이 게이트로 이미 강제되고 있다.
- **AR-1**: `domain`은 `org.springframework..`, `jakarta.persistence..`, `com.overmind.adapter..`에 의존할 수 없다.
- **AR-2**: `application`은 `com.overmind.adapter..`에 의존할 수 없다.
- **AR-4/INV-01 (`ProviderNameLeakTest`)**: `src/main/java/com/overmind/domain`과 `.../application` 아래 **모든 줄**(주석·Javadoc 포함)에서 `claude`, `chatgpt`, `openai`, `anthropic`, `gemini`, `llama`, `mistral`, `bedrock`, `vertex`, `gpt`가 **대소문자 무시**로 발견되면 실패한다. **예시를 쓸 때 실제 클라이언트 이름을 적지 말 것** — `source.client` 예시는 `"example-client"` 같은 중립 문자열을 쓴다.
- **`ddl-auto: validate`** 고정. 엔티티는 Flyway 마이그레이션이 만든 스키마와 정확히 일치해야 한다. 스키마 변경은 반드시 새 `V*__*.sql`로만.
- **마이그레이션 해시 가드**: 새 마이그레이션 파일을 추가한 뒤 `./gradlew updateMigrationChecksums`를 실행해야 한다. 이미 기록된 파일은 수정 불가(forward-only).
- **테스트 계층 게이트 (`TestTierBoundaryTest`)**: `@SpringBootTest`를 다는 클래스는 반드시 `@Tag("integration")`을 함께 달고 `PostgresTestBase`를 상속한다. 태그 없는 `@SpringBootTest`는 실패한다.
- **0건 실행 바닥**: `test`/`integrationTest`/`guardrailTest`가 0건을 실행하면 실패한다.
- **log.md 동반 갱신**: `src/`, `build.gradle.kts`, `settings.gradle.kts`, `.github/`, `docs/harness/`, `docs/superpowers/`, `docs/arch/`, `docs/requirements/`, `AGENTS.md`, `CLAUDE.md` 중 무엇이든 고치면 **같은 PR 범위 안에서** `log.md`를 갱신해야 CI가 통과한다.
- **커밋 전 `./gradlew verify`와 `./gradlew guardrails`가 둘 다 통과**해야 한다.
- **gitleaks는 로컬에 없으면 조용히 건너뛴다. 실제 게이트는 CI다.** 이 플랜을 쓰는 동안
  실제로 밟은 함정이다 — 문서에 적은 예시 시크릿(`cursor-secret=<32자 hex>`)이
  `generic-api-key` 규칙에 엔트로피 4.0으로 걸려 CI `guardrails`가 빨개졌다.
  **테스트든 문서든 `key=<고엔트로피 문자열>` 모양을 소스에 남기지 않는다.** 길이가
  필요하면 낱말을 반복해 채운다. 로컬에서 미리 보려면 gitleaks 바이너리를 받아
  `gitleaks detect --source . --no-git`으로 돌린다. **가드를 `.gitleaks.toml` 예외로
  무마하지 않는다** — 잡은 것이 진짜 시크릿이 아니어도, 잡은 규칙은 옳다.
- 테스트 클래스 이름 `FlywayMigrationTest`, `PostgresTestBase`는 `TestTierBoundaryTest`의 **앵커**다. 이름을 바꾸면 그 게이트도 같이 고쳐야 한다.

### 실행 환경

```bash
./gradlew verify        # compile + L1 + ArchUnit + L2
./gradlew guardrails    # 문서 상한, ddl-auto, 마이그레이션 해시, log.md, gitleaks
./gradlew test          # L1만
./gradlew integrationTest   # L2만 (Docker 필요)
```

L2는 Docker가 있어야 돈다. Docker가 없는 환경에서는 `verify`가 완주하지 못하므로 **"통과"가 아니라 "실행 불가"로 보고**한다.

- [ ] **Step 1: 실패하는 테스트를 쓴다**

`src/test/java/com/overmind/domain/memory/DomainValueTest.java`:

```java
package com.overmind.domain.memory;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

import com.overmind.domain.DomainValidationException;
import java.nio.charset.StandardCharsets;
import org.junit.jupiter.api.Test;

/** L1. 스펙 §3, §4.2의 도메인 생성 규칙. */
class DomainValueTest {

    private static String utf8Bytes(int byteCount) {
        // '가'는 UTF-8에서 3 bytes다. byteCount가 3의 배수가 아니면 'a'로 채운다.
        StringBuilder sb = new StringBuilder();
        int remaining = byteCount;
        while (remaining >= 3) {
            sb.append('가');
            remaining -= 3;
        }
        sb.append("a".repeat(remaining));
        return sb.toString();
    }

    @Test
    void content_rejects_blank() {
        assertThatThrownBy(() -> ObservationContent.of("   \n\t "))
                .isInstanceOf(DomainValidationException.class);
    }

    @Test
    void content_rejects_null() {
        assertThatThrownBy(() -> ObservationContent.of(null))
                .isInstanceOf(DomainValidationException.class);
    }

    @Test
    void content_accepts_exactly_16_kib_of_utf8() {
        String value = utf8Bytes(16 * 1024);
        assertThat(value.getBytes(StandardCharsets.UTF_8)).hasSize(16 * 1024);

        ObservationContent content = ObservationContent.of(value);

        assertThat(content.utf8Size()).isEqualTo(16 * 1024);
    }

    @Test
    void content_rejects_one_byte_over_16_kib() {
        String value = utf8Bytes(16 * 1024) + "a";

        assertThatThrownBy(() -> ObservationContent.of(value))
                .isInstanceOf(DomainValidationException.class);
    }

    @Test
    void content_limit_counts_bytes_not_characters() {
        // 문자 수로 세면 통과하고 byte 수로 세면 거부되는 지점.
        String value = "가".repeat(16 * 1024 / 3 + 1);
        assertThat(value.length()).isLessThan(16 * 1024);
        assertThat(value.getBytes(StandardCharsets.UTF_8).length).isGreaterThan(16 * 1024);

        assertThatThrownBy(() -> ObservationContent.of(value))
                .isInstanceOf(DomainValidationException.class);
    }

    @Test
    void project_key_accepts_lowercase_ascii_forms() {
        assertThat(ProjectKey.of("overmind").value()).isEqualTo("overmind");
        assertThat(ProjectKey.of("0").value()).isEqualTo("0");
        assertThat(ProjectKey.of("a.b_c-d").value()).isEqualTo("a.b_c-d");
    }

    @Test
    void project_key_rejects_invalid_forms() {
        assertThatThrownBy(() -> ProjectKey.of("Overmind"))
                .isInstanceOf(DomainValidationException.class);
        assertThatThrownBy(() -> ProjectKey.of("-leading-dash"))
                .isInstanceOf(DomainValidationException.class);
        assertThatThrownBy(() -> ProjectKey.of(".leading-dot"))
                .isInstanceOf(DomainValidationException.class);
        assertThatThrownBy(() -> ProjectKey.of("has space"))
                .isInstanceOf(DomainValidationException.class);
        assertThatThrownBy(() -> ProjectKey.of(""))
                .isInstanceOf(DomainValidationException.class);
        assertThatThrownBy(() -> ProjectKey.of("프로젝트"))
                .isInstanceOf(DomainValidationException.class);
    }

    @Test
    void project_key_accepts_128_chars_and_rejects_129() {
        assertThat(ProjectKey.of("a".repeat(128)).value()).hasSize(128);

        assertThatThrownBy(() -> ProjectKey.of("a".repeat(129)))
```

```java
package com.overmind.domain.memory;

import com.overmind.domain.DomainValidationException;
import java.time.Clock;
import java.time.Duration;
import java.time.Instant;

/**
 * 호출자가 준 관측 시각을 검증한다.
 *
 * <p>클라이언트 시계는 서버보다 조금 앞설 수 있으므로 5분까지 허용한다. 그 이상은
 * 시계 오차가 아니라 잘못된 값으로 본다. {@code Clock}을 주입받아 테스트에서 시각을 고정한다.
 */
public final class ObservedAtPolicy {

    public static final Duration MAX_FUTURE_SKEW = Duration.ofMinutes(5);

    private final Clock clock;

    public ObservedAtPolicy(Clock clock) {
        this.clock = clock;
    }

    /** 통과하면 받은 값을 그대로 돌려준다. */
    public Instant validate(Instant observedAt) {
        if (observedAt == null) {
            throw new DomainValidationException("observed_at 이 없습니다");
        }
        Instant limit = clock.instant().plus(MAX_FUTURE_SKEW);
        if (observedAt.isAfter(limit)) {
            throw new DomainValidationException(
                    "observed_at 이 허용 범위를 벗어났습니다. 서버 시각 기준 "
                            + MAX_FUTURE_SKEW.toMinutes()
                            + "분 이후까지만 허용합니다");
        }
        return observedAt;
    }
}
```

```sql
-- M0 스키마. observation은 append-only event log다 (스펙 §2.2).
-- 일반 처리 경로에 update/delete가 없으므로 트리거는 두지 않는다 — 그 강제는
-- persistence port에 해당 연산을 만들지 않는 것으로 한다 (스펙 §4.2).

CREATE TABLE memory_subject (
    id          uuid        PRIMARY KEY,
    type        text        NOT NULL,
    subject_key text,
    created_at  timestamptz NOT NULL,

    CONSTRAINT memory_subject_type_known
        CHECK (type IN ('USER', 'PROJECT')),

    -- USER에는 key가 없고 PROJECT에는 반드시 있다.
    CONSTRAINT memory_subject_key_matches_type
        CHECK ((type = 'USER' AND subject_key IS NULL)
            OR (type = 'PROJECT' AND subject_key IS NOT NULL)),

    -- PROJECT key는 1~128자 소문자 ASCII 안정 키다.
    CONSTRAINT memory_subject_project_key_form
        CHECK (subject_key IS NULL
            OR (char_length(subject_key) BETWEEN 1 AND 128
                AND subject_key ~ '^[a-z0-9][a-z0-9._-]*$')),

    CONSTRAINT memory_subject_type_key_unique
        UNIQUE (type, subject_key)
);

-- USER는 정확히 하나만 존재한다. (type, subject_key) unique는 subject_key가 NULL이면
-- 중복을 막지 못하므로 partial unique index가 따로 필요하다.
CREATE UNIQUE INDEX memory_subject_single_user
    ON memory_subject ((true))
    WHERE type = 'USER';

CREATE TABLE observation (
    id                     uuid        PRIMARY KEY,
    subject_id             uuid        NOT NULL,
    idempotency_key        text        NOT NULL,
    content                text        NOT NULL,
    observed_at            timestamptz NOT NULL,
    created_at             timestamptz NOT NULL,
    source_client          text        NOT NULL,
    source_conversation_id text        NOT NULL,
    source_message_id      text        NOT NULL,
    ingestion_type         text        NOT NULL,
    input_schema_version   integer     NOT NULL,

    -- cascade delete를 두지 않는다. subject 삭제로 observation이 조용히 사라지면
    -- append-only 불변식이 DB 수준에서 깨진다 (스펙 §4.2).
    CONSTRAINT observation_subject_fk
        FOREIGN KEY (subject_id) REFERENCES memory_subject (id),

    CONSTRAINT observation_idempotency_key_unique
        UNIQUE (idempotency_key),

    CONSTRAINT observation_content_not_blank
        CHECK (btrim(content) <> ''),

    CONSTRAINT observation_content_size
        CHECK (octet_length(content) <= 16384),

    CONSTRAINT observation_idempotency_key_size
        CHECK (octet_length(idempotency_key) BETWEEN 1 AND 256),

    CONSTRAINT observation_source_client_size
        CHECK (octet_length(source_client) BETWEEN 1 AND 128),

    CONSTRAINT observation_source_conversation_id_size
        CHECK (octet_length(source_conversation_id) BETWEEN 1 AND 512),

    CONSTRAINT observation_source_message_id_size
        CHECK (octet_length(source_message_id) BETWEEN 1 AND 512),

    CONSTRAINT observation_ingestion_type_known
        CHECK (ingestion_type IN ('DIRECT_MCP')),

    CONSTRAINT observation_input_schema_version_positive
        CHECK (input_schema_version >= 1)
);

-- recall의 정렬과 정확히 같은 순서다 (스펙 §4.4, §5.3).
CREATE INDEX observation_recall_keyset
    ON observation (subject_id, observed_at DESC, created_at DESC, id DESC);
```

```java
package com.overmind.adapter.out.persistence;

import static org.assertj.core.api.Assertions.assertThat;

import com.overmind.application.port.ObservationRepository;
import com.overmind.application.port.SubjectRepository;
import com.overmind.domain.memory.*;
import com.overmind.support.PostgresTestBase;
import java.time.Instant;
import java.util.List;
import java.util.UUID;
import java.util.concurrent.*;
import org.junit.jupiter.api.Tag;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;

/** L2. 스펙 §7 — 동시 생성이 하나로 수렴한다. */
@Tag("integration")
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.NONE)
class InsertOrFindConcurrencyTest extends PostgresTestBase {

    @Autowired private SubjectRepository subjects;
    @Autowired private ObservationRepository observations;

    private static <T> List<T> runConcurrently(int threads, Callable<T> task) throws Exception {
        ExecutorService pool = Executors.newFixedThreadPool(threads);
        CountDownLatch gate = new CountDownLatch(1);
        List<Future<T>> futures =
                java.util.stream.IntStream.range(0, threads)
                        .mapToObj(
                                i ->
                                        pool.submit(
                                                () -> {
                                                    gate.await();
                                                    return task.call();
                                                }))
                        .toList();
        gate.countDown();
        try {
            List<T> results = new java.util.ArrayList<>();
            for (Future<T> f : futures) {
                results.add(f.get(30, TimeUnit.SECONDS));
            }
            return results;
        } finally {
            pool.shutdownNow();
        }
    }

    @Test
    void concurrent_project_creation_converges_on_one_subject() throws Exception {
        ProjectKey key = ProjectKey.of("race-" + UUID.randomUUID().toString().substring(0, 8));
```

```java
package com.overmind.adapter.out.persistence;

import com.overmind.application.port.SubjectRepository;
import com.overmind.domain.memory.MemorySubject;
import com.overmind.domain.memory.ProjectKey;
import jakarta.persistence.EntityManager;
import java.time.Clock;
import java.util.List;
import java.util.Optional;
import java.util.UUID;
import org.springframework.stereotype.Repository;
import org.springframework.transaction.annotation.Transactional;

@Repository
public class SubjectRepositoryAdapter implements SubjectRepository {

    private final EntityManager entityManager;
    private final Clock clock;

    public SubjectRepositoryAdapter(EntityManager entityManager, Clock clock) {
        this.entityManager = entityManager;
        this.clock = clock;
    }

    @Override
    @Transactional
    public MemorySubject findOrCreateUser() {
        // 충돌해도 트랜잭션이 더럽혀지지 않는다. DO NOTHING이므로 이미 있으면 0행이 돌아온다.
        insertIgnoringConflict(UUID.randomUUID(), "USER", null);
        UUID id = selectId("USER", null);
        return MemorySubject.user(id);
    }

    @Override
    @Transactional
    public MemorySubject findOrCreateProject(ProjectKey key) {
        insertIgnoringConflict(UUID.randomUUID(), "PROJECT", key.value());
        UUID id = selectId("PROJECT", key.value());
        return MemorySubject.project(id, key);
    }

    @Override
    @Transactional(readOnly = true)
    public Optional<MemorySubject> findProject(ProjectKey key) {
        List<?> rows =
                entityManager
                        .createNativeQuery(
                                "SELECT id FROM memory_subject"
                                        + " WHERE type = 'PROJECT' AND subject_key = :key")
                        .setParameter("key", key.value())
                        .getResultList();
        if (rows.isEmpty()) {
            return Optional.empty();
        }
        return Optional.of(MemorySubject.project(toUuid(rows.get(0)), key));
    }

    private void insertIgnoringConflict(UUID id, String type, String subjectKey) {
        entityManager
                .createNativeQuery(
                        "INSERT INTO memory_subject (id, type, subject_key, created_at)"
                                + " VALUES (:id, :type, :key, :now)"
                                + " ON CONFLICT DO NOTHING")
                .setParameter("id", id)
                .setParameter("type", type)
                .setParameter("key", subjectKey)
                .setParameter("now", clock.instant())
                .executeUpdate();
    }

    private UUID selectId(String type, String subjectKey) {
        String sql =
                subjectKey == null
                        ? "SELECT id FROM memory_subject WHERE type = 'USER'"
                        : "SELECT id FROM memory_subject"
                                + " WHERE type = :type AND subject_key = :key";
        var query = entityManager.createNativeQuery(sql);
        if (subjectKey != null) {
            query.setParameter("type", type).setParameter("key", subjectKey);
        }
        return toUuid(query.getSingleResult());
    }

    private static UUID toUuid(Object raw) {
        return raw instanceof UUID uuid ? uuid : UUID.fromString(raw.toString());
    }
}
```

```java
public TransactionBoundary transactions() {
    return new TransactionBoundary() {
        @Override
        public <T> T inTransaction(java.util.function.Supplier<T> work) {
            Map<String, MemorySubject> subjectsBefore = new LinkedHashMap<>(subjectsByKey);
            Map<String, Observation> observationsBefore = new LinkedHashMap<>(observationsByKey);

                observationsByKey.clear();
                observationsByKey.putAll(observationsBefore);
                throw e;
            }
        }
    };
```

```java
import com.overmind.application.MemoryErrorCode;

/** 스펙 §5.1. 한 번의 호출은 정확히 하나의 raw observation을 만든다. */
public class RememberMemory {

    private final SubjectRepository subjects;
    private final ObservationRepository observations;
    private final Clock clock;
    private final ObservedAtPolicy observedAtPolicy;

    public RememberMemory(
            SubjectRepository subjects,
            ObservationRepository observations,
            TransactionBoundary transactions,
            Clock clock) {
        this.subjects = subjects;
        this.observations = observations;
        this.transactions = transactions;
        this.clock = clock;
        this.observedAtPolicy = new ObservedAtPolicy(clock);
    }

    public RememberResult handle(RememberCommand command) {
        // 값 검증은 트랜잭션 밖에서 한다 — DB를 건드리지 않으므로 열 이유가 없다.
        // 그 다음 subject 생성부터 insert까지를 하나의 트랜잭션으로 묶는다.
        // 쪼개면 subject가 커밋된 뒤 insert가 실패해 빈 PROJECT가 남는다 (스펙 §5.1 금지).
        return transactions.inTransaction(() -> handleInTransaction(command));
    }

    private RememberResult handleInTransaction(RememberCommand command) {
        // 1. 값 검증이 먼저다. 여기서 떨어지면 subject는 만들어지지 않는다.
        IdempotencyKey key = IdempotencyKey.of(command.idempotencyKey());
        ObservationContent content = ObservationContent.of(command.content());
        SourceReference source =
                SourceReference.of(
                        command.sourceClient(),
                        command.sourceConversationId(),
                        command.sourceMessageId());
        java.time.Instant observedAt = observedAtPolicy.validate(command.observedAt());
        ProjectKey projectKey = validateSubjectShape(command);

        // 2. 이미 있으면 의미 필드를 비교한다.
        Optional<Observation> existing = observations.findByIdempotencyKey(key);
        if (existing.isPresent()) {
            Observation stored = existing.get();
            if (!sameRequest(stored, command, content, observedAt, source, projectKey)) {
                throw new MemoryException(
                        MemoryErrorCode.IDEMPOTENCY_CONFLICT,
                        "같은 idempotency key로 다른 요청이 들어왔습니다");
            }
            return new RememberResult(stored.id(), false);
        }

        // 3. 여기서부터 subject를 만든다.
        MemorySubject subject =
                projectKey == null
                        ? subjects.findOrCreateUser()
                        : subjects.findOrCreateProject(projectKey);

        UUID candidateId = UUID.randomUUID();
        Observation stored =
                observations.insertIfAbsent(
                        Observation.create(
                                candidateId,
                                subject,
                                key,
                                content,
                                observedAt,
                                clock.instant(),
                                source,
                                IngestionType.DIRECT_MCP,
                                command.inputSchemaVersion()));

        if (!stored.id().equals(candidateId)) {
            // 경쟁에서 졌다. 저장된 쪽이 같은 요청인지 확인한다.
            if (!sameRequest(stored, command, content, observedAt, source, projectKey)) {
                throw new MemoryException(
                        MemoryErrorCode.IDEMPOTENCY_CONFLICT,
                        "같은 idempotency key로 다른 요청이 들어왔습니다");
            }
            return new RememberResult(stored.id(), false);
        }
        return new RememberResult(stored.id(), true);
    }

    private ProjectKey validateSubjectShape(RememberCommand command) {
        if (command.subjectType() == SubjectType.USER) {
            if (command.projectKey() != null) {
                throw new MemoryException(
                        MemoryErrorCode.INVALID_ARGUMENT, "USER subject에는 project key를 줄 수 없습니다");
            }
            return null;
        }
        if (command.projectKey() == null) {
            throw new MemoryException(
                    MemoryErrorCode.INVALID_ARGUMENT, "PROJECT subject에는 project key가 필요합니다");
        }
        return ProjectKey.of(command.projectKey());
    }

    private boolean sameRequest(
            Observation stored,
            RememberCommand command,
            ObservationContent content,
            java.time.Instant observedAt,
            SourceReference source,
            ProjectKey projectKey) {
        return stored.subject().type() == command.subjectType()
                && java.util.Objects.equals(
                        stored.subject().projectKey().orElse(null), projectKey)
                && stored.content().equals(content)
                && stored.observedAt().equals(observedAt)
                && stored.source().equals(source)
                && stored.ingestionType() == IngestionType.DIRECT_MCP
                && stored.inputSchemaVersion() == command.inputSchemaVersion();
    }
}
```

토큰 형식: `v1.<base64url(payload)>.<base64url(hmacSha256(secret, "v1." + payloadB64))>`

payload는 `observedAtEpochNanos|createdAtEpochNanos|uuid|fingerprint` 형태의 평문이다. 서명 비교는 반드시 `MessageDigest.isEqual`로 한다 — `String.equals`는 타이밍 차이를 낸다.

```java
package com.overmind.adapter.out.security;

import com.overmind.application.MemoryErrorCode;
import com.overmind.application.MemoryException;
import com.overmind.application.memory.RecallCursor;
import com.overmind.application.port.CursorCodec;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.time.Instant;
import java.util.Base64;
import java.util.UUID;
import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;

/** 스펙 §5.3. 서버만 만들 수 있고 서버 상태를 쓰지 않는 cursor. */
public class HmacCursorCodec implements CursorCodec {

    private static final String VERSION = "v1";
    private static final String ALGORITHM = "HmacSHA256";
    private static final Base64.Encoder ENC = Base64.getUrlEncoder().withoutPadding();
    private static final Base64.Decoder DEC = Base64.getUrlDecoder();

    private final byte[] secret;

    public HmacCursorCodec(byte[] secret) {
        if (secret == null || secret.length < 32) {
            throw new IllegalArgumentException("cursor HMAC secret은 최소 32 bytes여야 합니다");
        }
        this.secret = secret.clone();
    }

    @Override
    public String encode(RecallCursor cursor) {
        String payload =
                cursor.observedAt().getEpochSecond()
                        + ":" + cursor.observedAt().getNano()
                        + "|" + cursor.createdAt().getEpochSecond()
                        + ":" + cursor.createdAt().getNano()
                        + "|" + cursor.id()
                        + "|" + cursor.filterFingerprint();
        String body = VERSION + "." + ENC.encodeToString(payload.getBytes(StandardCharsets.UTF_8));
        return body + "." + ENC.encodeToString(sign(body));
    }

    @Override
    public RecallCursor decode(String token, String expectedFingerprint) {
        if (token == null || token.isBlank()) {
            throw invalid();
        }
        int lastDot = token.lastIndexOf('.');
        if (lastDot < 0) {
            throw invalid();
        }
        String body = token.substring(0, lastDot);
        if (!body.startsWith(VERSION + ".")) {
            throw invalid();
        }
        byte[] presented;
        String payload;
        try {
            presented = DEC.decode(token.substring(lastDot + 1));
            payload =
                    new String(
                            DEC.decode(body.substring(VERSION.length() + 1)),
                            StandardCharsets.UTF_8);
        } catch (IllegalArgumentException e) {
            throw invalid();
        }
        if (!MessageDigest.isEqual(sign(body), presented)) {
            throw invalid();
        }
        String[] parts = payload.split("\\|");
        if (parts.length != 4) {
            throw invalid();
        }
        if (!parts[3].equals(expectedFingerprint)) {
            // filter가 바뀌면 keyset 위치의 의미가 달라진다. 첫 페이지로 되돌리지 않는다.
            throw invalid();
        }
        try {
            return new RecallCursor(
                    parseInstant(parts[0]), parseInstant(parts[1]), UUID.fromString(parts[2]),
                    parts[3]);
        } catch (RuntimeException e) {
            throw invalid();
        }
    }

    private static Instant parseInstant(String raw) {
        String[] halves = raw.split(":");
        return Instant.ofEpochSecond(Long.parseLong(halves[0]), Long.parseLong(halves[1]));
    }

    private byte[] sign(String body) {
        try {
            Mac mac = Mac.getInstance(ALGORITHM);
            mac.init(new SecretKeySpec(secret, ALGORITHM));
            return mac.doFinal(body.getBytes(StandardCharsets.UTF_8));
        } catch (java.security.GeneralSecurityException e) {
            throw new IllegalStateException("HMAC 계산 실패", e);
        }
    }

    private static MemoryException invalid() {
        // 메시지에 토큰 원문을 넣지 않는다 (스펙 §5.5, §8).
        return new MemoryException(MemoryErrorCode.INVALID_CURSOR, "cursor가 유효하지 않습니다");
    }
}
```

`RecallCursor.filterFingerprint`는 subject id를 문자열로 정렬해 이어붙인 뒤 SHA-256 해 hex 앞 16자를 돌려준다.

**테스트 시크릿 주의 — 실제로 CI를 빨갛게 만든 함정이다.** `HmacCursorCodec`이 32 bytes 미만을 거부하므로 테스트 시크릿은 32 bytes 이상이어야 한다. 그런데 **길이를 hex나 무작위 문자열로 채우면 gitleaks가 그것을 진짜 시크릿으로 잡는다.** 이 플랜의 초안이 정확히 그렇게 실패했다 — `cursor-secret=<32자 hex>`가 `generic-api-key` 규칙에 엔트로피 4.0으로 걸렸다. **낱말을 반복해 길이를 채운다.** 가드를 예외 처리로 무마하지 않는다.

  - `RecallResult(List<RecallItem> observations, String nextCursor)` — record

  - `RecallMemory.DEFAULT_CONTENT_BUDGET_BYTES = 2 * 1024 * 1024` — 운영 기본값. 3-인자 생성자가 이 값을 쓴다

**⚠ 스펙 §5.4의 예산은 공개 API로는 도달할 수 없다 — 설계 결함이다.**
`limit` 최대 100(§5.2) × content 최대 16 KiB(§4.2) = **1,638,400 bytes**로, 2 MiB(2,097,152)를 넘을 수 없다. 즉 운영 기본값에서 예산 로직은 **절대 발화하지 않는다.** 예산 코드를 통째로 지워도 어떤 요청도 달라지지 않는다.

그래서 예산을 생성자로 주입받게 만든다. 테스트는 작은 예산으로 **로직 자체가 도는 것**을 확인하고, 운영 기본값은 그대로 둔다 — 방어적 상한으로서는 여전히 의미가 있다(§4.2나 §5.2의 수치가 나중에 커지면 그때 발화한다).

**이 불일치는 사용자에게 보고했다.** 세 수치 중 하나를 바꿀지는 결정 사항이며, 이 플랜은 스펙 수치를 그대로 따른다.

**규칙 (스펙 §5.2·§5.4):**
- project key가 없으면 USER만. 있으면 USER + 해당 PROJECT.
- 없는 PROJECT는 `SUBJECT_NOT_FOUND`. **recall은 subject를 만들지 않는다.**
- PROJECT는 있는데 observation이 없으면 정상 빈 결과.
- 응답에 conversation/message ID, `created_at`, idempotency key, USER 내부 key, OIDC subject, total count를 넣지 않는다.
- 예산이 차면 **마지막으로 완전히 포함한 observation 기준으로** `nextCursor`를 만든다.

**T6~T7 인수 후 검증 보완 (2026-09-03):** 아래 예시의 `Instant.now()`와 무작위 UUID는
마지막 정렬 기준인 id의 동률 경계를 보장하지 않는다. 실제 테스트는 `observed_at`과
`created_at`을 모두 고정하고, PostgreSQL UUID 순서를 검증할 수 있는 ID를 지정한다.
정확한 순서·개수·집합을 확인하며 선택하지 않은 subject도 제외되는지 검사한다.
별도 통합 테스트는 RememberMemory·RecallMemory·HMAC codec과 실제 SQL을 연결해
응답 예산으로 잘린 뒤의 커서 순회를 검증한다. T7에서 확인한 대로 기본 2 MiB 예산은

**실패 주입 주의.** 롤백 검사는 **도메인은 통과하지만 DB가 거부하는** 값이 필요하다. 도메인이 이미 content 16 KiB와 schema version ≥ 1을 막으므로 그 둘로는 만들 수 없다. **없는 subject를 가리키는 observation**을 넣어 `observation_subject_fk`를 깨뜨린다 — 도메인은 통과하고 DB가 거부한다.

**Interfaces:**
- Consumes: Task 4·6·7
- Produces: `findPage`의 실제 SQL 구현. 시그니처는 Task 4에서 정한 그대로

**SQL (cursor 있음):**

```sql
SELECT o.* FROM observation o
WHERE o.subject_id IN (:subjectIds)
  AND (o.observed_at, o.created_at, o.id) < (:cursorObservedAt, :cursorCreatedAt, :cursorId)
ORDER BY o.observed_at DESC, o.created_at DESC, o.id DESC
LIMIT :limitPlusOne
```

PostgreSQL의 행 비교(row constructor comparison)를 쓴다. `observed_at < :x OR (observed_at = :x AND ...)`로 풀어 쓰면 인덱스를 못 타는 형태가 되기 쉽다. cursor가 없으면 두 번째 조건절만 뺀다.

```java
@AutoConfigureMockMvc
class LogHygieneTest extends PostgresTestBase {

    @Autowired private RecallMemory recall;

    private static final String MAGIC_IDEM = "MAGICIDEM" + "9c2e4d";
    private static final String MAGIC_PROJECT = "magicproject-5a8b1c";
    private static final String MAGIC_CONVERSATION = "MAGICCONV" + "2d6f9a";
    private static final String MAGIC_MESSAGE = "MAGICMSG" + "4b7e3f";

        return new RememberCommand(
                idem, SubjectType.PROJECT, MAGIC_PROJECT, content,

    }

        capture.assertNoOccurrenceOf(

    void a_successful_remember_logs_nothing_sensitive() {

        }

            assertClean(capture);
        }
    }

    void an_invalid_cursor_logs_nothing_sensitive() {
        String magicCursor = "MAGICCURSOR" + "8e1d5b";

        try (LogCapture capture = LogCapture.start()) {
            catchThrowable(() -> recall.handle(new RecallQuery(null, 10, magicCursor)));
            capture.assertNoOccurrenceOf(magicCursor);
        }
    }

    void a_missing_project_does_not_log_the_project_key() {
        try (LogCapture capture = LogCapture.start()) {
            catchThrowable(() -> recall.handle(new RecallQuery(MAGIC_PROJECT + "-absent", 10, null)));
            capture.assertNoOccurrenceOf(MAGIC_PROJECT);
        }
```

```java
package com.overmind.adapter.in.mcp;

import static org.assertj.core.api.Assertions.assertThat;

import com.overmind.application.memory.*;
import com.overmind.domain.memory.SubjectType;
import com.overmind.support.PostgresTestBase;
import java.time.Instant;
import java.util.UUID;
import org.junit.jupiter.api.Tag;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;

/** L2. 스펙 §10 AC 1~6, 8. */
@Tag("integration")
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.NONE)
class CrossClientAcceptanceTest extends PostgresTestBase {

    @Autowired private RememberMemory remember;
    @Autowired private RecallMemory recall;

    @Test
    void what_one_client_stores_another_client_recalls() {
        String marker = "cross-client-" + UUID.randomUUID();
        remember.handle(
                new RememberCommand(
                        "idem-" + marker, SubjectType.USER, null, marker,
                        Instant.parse("2026-09-02T10:00:00Z"),
                        "client-a", "conv-a", "msg-a", 1));

        RecallResult seenByOther = recall.handle(new RecallQuery(null, 100, null));

        assertThat(seenByOther.observations()).extracting(RecallItem::content).contains(marker);
    }

    @Test
    void a_project_recall_returns_user_and_project_together_newest_first() {
        String project = "acc-" + UUID.randomUUID().toString().substring(0, 8);
        remember.handle(
                new RememberCommand(
                        "idem-u-" + project, SubjectType.USER, null, "user side",
                        Instant.parse("2026-09-02T09:00:00Z"), "client-a", "c", "m", 1));
        remember.handle(
                new RememberCommand(
                        "idem-p-" + project, SubjectType.PROJECT, project, "project side",
                        Instant.parse("2026-09-02T10:00:00Z"), "client-b", "c", "m", 1));

        RecallResult result = recall.handle(new RecallQuery(project, 100, null));

        assertThat(result.observations()).extracting(RecallItem::content)
                .containsSubsequence("project side", "user side");
    }

    @Test
    void a_retry_does_not_duplicate() {
        String idem = "idem-retry-" + UUID.randomUUID();
        RememberCommand command =
                new RememberCommand(
                        idem, SubjectType.USER, null, "retried fact",
                        Instant.parse("2026-09-02T10:00:00Z"), "client-a", "c", "m", 1);

        RememberResult first = remember.handle(command);
        RememberResult second = remember.handle(command);

        assertThat(second.created()).isFalse();
        assertThat(second.observationId()).isEqualTo(first.observationId());
    }
}
```
